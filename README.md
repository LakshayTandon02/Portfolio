## 💻 Run Locally

To explore or modify this project on your local machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/LakshayTandon02/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

**Note:** These instructions assume the repository contains a standard Vite setup. Check `package.json` for the actual scripts and required environment variables. If the project requires a backend, configure it according to the project files.
